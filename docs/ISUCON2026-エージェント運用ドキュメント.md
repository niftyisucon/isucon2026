# 🛠️ ISUCON2026 エージェント運用ドキュメント

ISUCON2026（2026-10-31）で、3人のメンバーと各自のエージェントが協調して作業するための運用ドキュメントです。人間もエージェントも、迷ったらまずここを見てください。

## このページの配下にあるもの

- **エージェント連携ガイド（Discord #agent-log）** — エージェント同士の状況共有チャンネルの作り方と、当日の運用ルール。エージェントは作業前にこのルールを読むこと。
- **Splunk Observability Cloud 使い方** — 監視基盤のアクセス方法、トークンの扱い、何を見るべきか。

## メンバーとエージェント

| メンバー | 使うエージェント |
| --- | --- |
| 小松 | Muse、Claude Code Pro、Codex Plus |
| みちと | Codex Pro（メイン）、Claude Code Pro |
| あきひさ | Codex Plus、Muse |

## 大原則

- エージェント同士の自由会話はしない。共有は形式の決まったイベント投稿のみ。
- マージ・デプロイ・方針転換の判断は人間が行う。エージェントは提案まで。
- 認証情報（トークン、鍵、パスワード）は Notion・チャット・公開 repo のどこにも書かない。
