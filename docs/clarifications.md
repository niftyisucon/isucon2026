## 各件の内容

### #46 Fly High賞の「前回比のスコア上昇幅」の「前回」とは（もなまっち、質問 12:15 / 回答 12:17）

- 質問: 「前回」は、直前に行った（0点ではない）負荷走行のスコアと、それまでのベストスコアのどちらですか。
- 回答: 直前に行った（0点ではない）負荷走行のスコアです。

### #41 FAILした負荷走行は特別賞の比較に含まれますか（もなまっち、質問 12:05 / 回答 12:11）

- 質問: スピード10倍賞の「チームで最初に計測したベンチマークスコア」と、Fly High賞の「前回比のスコア上昇幅」の「前回」に、FAIL（0点）の負荷走行は含まれますか。
- 回答: どちらも0点は含まれません。

### #40 激流賞の「スコアボードクローズ（17:00）後のスコアの伸び」の定義（もなまっち、質問 12:05 / 回答 12:10）

- 回答: (1) 伸びは、17:00時点のスコアと最終スコアの差で計算されます。(2)「17:00時点のスコア」は、17:00よりも前にEnqueueされた0点ではない最後の負荷走行のスコアを示します。

### #39 画像URLの検証について変更は認められていますか（全体公開・運営発、2026-10-31 12:02）

- 回答: マニュアルに記載があるとおり、署名と期限の形式や検証結果を変えてはいけません。有効期限については、ベンチマーカが許容する限り変更しても構いません。

### #32 最終チェックの制限時間の記載はありますか（team yuki2006、質問 11:50 / 回答 11:55）

- 質問: 負荷走行で「最終チェックで確定する制限時間内に」とありますが、時間自体の記載はありますか？
- 回答: 記載が漏れておりました。60秒以内に初期化を完了してください。

### #26 S3 を利用しても良いですか（全体公開・運営発、2026-10-31 11:40）

- 回答: ルール違反です。

### #21 ポータルの「通知を有効化する」が Failed to subscribe で失敗する（team1111、質問 10:45 / 回答 10:49）

- 回答: 現在は正しく動作していません。

### #20 europe1 / america1 の nginx から asia のアプリへ proxy_pass する構成は許容されますか（boulder、質問 10:45 / 回答 10:48）

- 質問の前提: サーバ間の通信は VPC のルートどおりルーターを経由し、リージョン間の遅延・帯域制限もそのまま受ける。ユーザーの接続先（X-Country-Code による振り分け）は変更しない。
- 回答: はい。

### #7 AGENTS.md は人間に対する絶対的なルールとして定義されていますか（こたまねぎ、質問 10:10 / 回答 10:12）

- 回答: その内容には回答できません。

### #6 CloudFormation で AZ の在庫不足エラーになり競技を開始できない（haigyo、質問 10:07 / 回答 10:14）

- 回答: AZ 上の在庫がなくなっているため、ポータルから生成される CloudFormation の `GetAvailabilityZoneFunction` 内の `ZoneIds = ['apne1-az2']` を `['apne1-az1']` もしくは `['apne1-az4']` に書き換えて再作成してください。

### #3 ベンチマーカー実行の自動化は許容されますか（あとで、質問 10:04 / 回答 10:05）

- 質問: ISUCON ポータルサイト以外から、ポータルサイトと類似のリクエストを送信することでベンチマーカーを実行することは許容されていますか？
- 回答: はい。
